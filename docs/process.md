# Процесс исследования: как это было сделано

Дата: 11 июля 2026. Инструменты: Apify, Gemini 2.5 (Flash + Pro), Python, Claude Code (3 параллельных суб-агента), Cloudflare Pages.

## Хронология и шаги

### 1. Сбор данных о целевом аккаунте (~10 мин)
- `apify/instagram-profile-scraper` → профиль @lotosinbloom: 4 824 подписчика, 2 889 постов, био, ссылки, related profiles (data/target/profile.json)
- `apify/instagram-scraper` → 100 последних постов с полными метриками (data/target/posts.json)
- Аудит воронки: WebFetch лендинга lotosinbloom.ru/beautybox и t.me/lotosclub27 (75 подписчиков — обнаружен разрыв воронки)

### 2. Дискавери конкурентов (~20 мин)
Четыре источника, чтобы не зависеть от одного:
- 11 поисковых выдач Instagram (`apify/instagram-search-scraper`) по ключам: «психолог для женщин», «женская психология», «медитация», «майндфулнесс», «нервная система» и др. → 215 уникальных кандидатов
- related profiles самого аккаунта (34 аккаунта соседней ниши)
- Веб-исследование рейтингов русскоязычных психологов в Instagram (trendhero и др.)
- Батч-скрейп 36 профилей-кандидатов → фильтр по размеру/активности/релевантности → **26 финальных, 4 яруса** (мега 1M+, лидеры ниши 50-400k, растущие 10-50k, пиры 3-7k)

### 3. Массовый сбор контента конкурентов (~15 мин)
- 3 параллельных запуска `apify/instagram-scraper` (по ~9 аккаунтов) → **1 040 постов** с метриками
- Разбивка по аккаунтам: data/competitors/posts/<username>.json

### 4. Количественный анализ (Python)
`scripts/analyze_account.py` по каждому аккаунту: частота постинга, микс форматов, медианы лайков/комментариев/просмотров, ER, длины подписей, топ-посты. Ключевые находки:
- Виральность ниши живёт на аутлаерах: max/median до 1600× у малых аккаунтов
- @_rybakova: 91% медианного охвата от базы — эталон качества контента
- Лидеры постят 5-6.5 раз/нед; подписи 850-1650 знаков; хэштеги мертвы (15% использования)

### 5. Качественный анализ паттернов (3 суб-агента параллельно, ~15 мин)
Каждый агент разобрал свой ярус: темы топ-постов, хуки дословно, CTA, монетизация, уроки для 5k-аккаунта:
- data/analysis/patterns_tier1.json — мега-эксперты (бот-воронки в 38-68% постов, «один оффер = месяц контента»)
- data/analysis/patterns_tier2.json — лидеры ниши (формула _rybakova пошагово, медиа-модель prosto.meditation)
- data/analysis/patterns_tier3.json — пиры (личное бьёт экспертное 25-100×, механики прорывов малых аккаунтов)

### 6. Видео-анализ виральных reels (Gemini 2.5 Flash, ~20 мин)
- Отбор №1 виральный reel каждого ключевого аккаунта + вирал цели → **13 роликов** (2.17M → 48k просмотров)
- Скачивание mp4 (свежие CDN-ссылки из скрейпа) → Gemini Files API → структурный разбор: хук дословно, структура по секундам, приёмы удержания, визуал, CTA, воспроизводимая формула (data/analysis/reels/)

### 7. Кросс-анализ и таксономия (Gemini 2.5 Pro)
- Топ-40 виральных постов всей ниши → таксономия: темы, формулы хуков, эмоциональные драйверы, share-триггеры (data/analysis/viral_taxonomy.json)
- 100 подписей цели → анализ тем/хуков/CTA/продающей способности (data/analysis/target_content_analysis.json)

### 8. Синтез
- Аудит 10 измерений с весами → 43/100 (data/analysis/audit_scores.json)
- Стратегия + воронка + контент-система (docs/growth_strategy.md)
- 4-недельный контент-план (docs/content_plan.md)
- 6 скриптов на проверенных формулах (docs/content_scripts.md)
- HTML-отчёт → Cloudflare Pages

## Ключевые открытия процесса (мета)

1. **Поиск Instagram отдаёт мелочь** — большие аккаунты пришли из веб-рейтингов и related profiles. Комбинировать источники обязательно.
2. **CDN-ссылки на видео протухают за часы** — качать сразу после скрейпа. Один ролик (@marya_london_) скачался битым (0.2MB), но Gemini всё равно разобрал его корректно (короткий тизер-формат подтверждён каптионом и метриками).
3. **Gemini иногда возвращает «двойной JSON»** при responseMimeType=application/json — лечится tolerant-парсером (raw_decode первого объекта).
4. **Лайки могут быть скрыты** (larangsovet, radmila_shakti) — просмотры надёжнее как метрика сравнения.
5. **Бюджет Apify**: весь сбор уложился в ~$5 (лимит бесплатного тарифа исчерпан в конце — при повторных прогонах повышать лимит или брать меньше выдач).

## Примечание: создание нового GitHub-репозитория из сессии

Сессионный GitHub-прокси Anthropic подменяет Authorization-заголовок на всех
запросах к api.github.com/github.com (проверено: запрос без токена и с фейковым
токеном аутентифицируются одинаково) и разрешает запись только в репозитории,
привязанные к сессии. Поэтому `POST /user/repos`, `create_repository` (MCP),
`PATCH` настроек и `/generate` из сессии заблокированы политикой.

Чтобы перенести проект в отдельный репозиторий: создать пустой
`agentic-mevist/lotosinbloom-growth` через браузер, затем в сессии:
`add_repo` → `bash scripts/push_to_new_repo.sh` (готовый скрипт в scripts/).

## v2 отчёта (та же дата, вторая итерация)

1. **Пароль**: Cloudflare Pages Functions `_middleware.js` — кука с SHA-256 токеном на 30 дней,
   стилизованная страница входа. Пароль защищает и HTML, и все медиа (один origin).
2. **Медиа**: bucket R2 `lotos-report-media` (14 виральных reels + 60 аватаров, 73 объекта),
   стриминг через Pages Function `media/[[path]].js` с поддержкой HTTP Range (перемотка видео).
   Аватары скачаны из CDN-ссылок скрейпа до их протухания (60/61 успешно).
3. **Круг доверия**: подписки Instagram закрыты; собраны 3 сигнала из имеющихся данных —
   18 @упоминаний в подписях, 5 отметок, 33 related-профиля графа → 56 аккаунтов,
   суб-агент профилировал 29 нишевых через веб-исследование (пресса, taplink, площадки).
   Ключевые находки: Сати Казанова — «my dear friend» в её подписи; саундхилер Ильдар
   Гиридхари уже был со-продюсером её ивента CHOICE; открытый слот позиционирования —
   «научная практика внутри женско-духовного мира».
4. **Отчёт**: аватары и ссылки во всех упоминаниях аккаунтов, встроенные видео в разборах
   reels, профиль-карточка цели в хиро, раздел «Круг доверия» с топ-6 коллабораций.

## v3 отчёта: превью ленты (та же дата, третья итерация)

Запрос: «как это будет выглядеть в ленте» + вопрос «обложка = кадр видео или отдельное фото?».

1. **Кадры Дарьи**: 8 её собственных reels скачаны (CDN-ссылки из скрейпа ещё жили),
   ~80 стоп-кадров извлечены ffmpeg (imageio-ffmpeg; у роликов разное разрешение —
   720×1280 и 1080×1920, кропы задаются долями, не пикселями). Вшитые
   караоке-субтитры и бейдж «2x» убираются кропом при повторной выгонке кадра
   из видео (jpg-вход у imageio-сборки ffmpeg не декодируется — только видео).
2. **Обложки**: scripts/generate_feed_previews.py — 6 обложек 1080×1350
   (4 reels = реальные кадры «говорю в камеру» + её антиква-система; 2 карусели =
   дизайн-обложки из фото-библиотеки) + мокап профиля (реальная шапка + 6 новых
   обложек поверх настоящих обложек последних постов, тайлы 3:4 как в текущем IG).
3. **Ответ на «кадр или фото»**: 13/13 виральных reels ниши открываются говорящей
   головой; её текущая практика (тревел-фото на обложках reels) прячет эксперта —
   в мокапе это видно как контраст рядов 1–2 против 3–4.
4. **Границы**: синтез внешности (изображение или видео) не выполнялся и при
   повторном запросе — нельзя верифицировать согласие человека на генерацию его
   лица. Альтернатива без потери ценности: реальные кадры + шаблонная типографика;
   воркфлоу самостоятельной ИИ-генерации передан в docs/ai_cover_workflow.md.
