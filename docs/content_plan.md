## Правила исполнения
1. **Батч-съёмка:** реелы недели снимаются за 1 день (пн-вечер предыдущей недели).
2. **Первый час после поста:** отвечать на каждый комментарий (сигнал алгоритму + ТИШИНА-конверсии).
3. **Понедельник — 30 мин аналитики:** просмотры/охват/сохранения каждого поста в таблицу; хук с лучшей досматриваемостью → тираж в следующей неделе.
4. **A/B хуков:** первые 3 сек можно переснимать отдельно — один контент, два хука, сравнить через 48ч (паттерн _rybakova: она месяц итерировала хуки, потом заперла формулу).
5. **Stories — минимум 3 кадра/день:** утренний ритуал, процесс, интерактив (опрос/квиз/вопрос). Stories не для охвата — для прогрева ядра.
6. **После виральной вспышки (>10k):** в течение 24ч выпустить продолжение серии (алгоритм раздаёт автора, пока горячо) + поднять ТИШИНА-пост в закреп.
