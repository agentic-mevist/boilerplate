# Speed Racer PKO Trainer

A push/fold trainer for 6-max, 10-big-blind **progressive knockout** tournaments
(GGPoker "Speed Racer" bounty format). It scores every decision with
**ICM + bounty** math and explains why.

Live: https://speed-racer-pko-trainer.donatizehelp.workers.dev

## Features
- **Train**: random spots (early, pre-bubble, bubble, ITM, final table) of three kinds:
  facing a shove, open-shove or fold, and shove + call in front. You get a verdict, an EV table
  under four models (Chip EV, ICM only, Chips + bounty, ICM + bounty), required-equity
  breakdowns, villain ranges and a 169-hand chart of the correct range for that exact spot.
- **Spot calculator**: rebuild a real hand (stacks, bounties, player types, ranges) and solve it.
- **Learn**: the strategy guide (bounty math, covering, the BB-ante trap, ICM, stages, HUD reads).
- **Settings**: buy-in split, field size, payout %, KO cash share, ante.

## Model
- Exact all-in resolution: side pots, split pots, bust order, progressive bounty splits.
- ICM: Malmuth-Harville, exact for ≤ 9 players, Monte Carlo (exponential race, common random numbers) otherwise.
- Bounty equity: chip share × all bounty money still in play + cash collected this hand.
- Villain ranges: top-X% by all-in equity; X from player type, adjusted for stack depth, position, covering and bubble.

## Develop
Plain static site, no build step (`site/`). Hand orderings in `site/js/ranking.js` are generated by
`npm run gen-ranking`. Run sanity tests with `npm test`; deploy with `npx wrangler deploy`.
