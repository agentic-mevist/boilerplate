# Custom card images

Drop an image here named after the card's default image (or, for cards without one,
the featured name in lowercase) and it replaces the default in the next render:

| File            | Card                                   |
|-----------------|----------------------------------------|
| isabella.jpg    | Twilight's Bella takes #1 (2005)       |
| emma.jpg        | Friends: Rachel has baby Emma (2000)   |
| madison.jpg     | A mermaid named Madison (1993)         |
| milano.jpg      | Who's the Boss? made Samantha (1985)   |
| jennifer.jpg    | Love Story's Jenny (1968)              |
| ashley.jpg      | A soap opera makes Ashley (1982)       |
| charlotte.jpg   | Charlotte closes in on #1 (2021)       |

Any extension works (.jpg, .png, .webp). Credits and captions go in `credits.json`:

    {"isabella": "Twilight (2008), Summit Entertainment",
     "isabella_caption": "Bella Swan in Twilight"}

Film and TV stills are copyrighted by their studios; using them is the
publisher's call (commentary/education may count as fair use, but platforms
can still issue copyright claims).
