PRODUCT VISION · WORKING NAME “RUSHES” · NOVEMBER 2026

Rushes: you direct, the agent edits, the app keeps both honest

A native Mac app that gives Claude Code, Codex or any other agent the eyes, hands and screen it needs to edit video, and gives you a calm place to watch, comment and approve.

The whole idea in three lines. The agent does almost all of the editing. You only do the parts that need taste: the brief, the review, the yes. The app does the parts that should never be left to luck: seeing the footage, enforcing the rules, showing the edit instantly and rendering it once.

01 Who does what

Three players, each doing only what it is best at

Most AI editors today blur these roles. The agent is asked to perceive, decide, police itself and render, and you are asked to babysit a terminal. Rushes splits the job cleanly. Every diagram below uses the same three colours.

YOU · the director

Taste and decisions

  • Drop footage and write a one-paragraph brief
  • Answer the few questions only you can answer
  • Watch the draft, leave comments by pointing at moments
  • Approve, or nudge a cut by hand when it’s faster

Never has to: scrub a timeline, hunt for retakes, fix mid-word cuts, wait for a render to see a change.

AGENT · the editor

Judgement at scale

  • Reads the footage “dossier” and picks the best takes
  • Writes the edit as small, explained steps
  • Asks instead of guessing when two options are close
  • Turns your comments into the next version

Never has to: touch pixels, run ffmpeg, remember your style, or claim it’s done without the checks passing.

APP · the edit suite

Senses, rules and screen

  • Makes proxies and runs every sense on your Mac
  • Holds the timeline: the one source of truth
  • Validates every change and snaps it to safe edges
  • Plays the edit instantly, renders once at the end

Never has to: decide what’s funny, what’s boring, or what your audience wants.

02 How it fits together

Your footage stays on the Mac. Only descriptions and decisions travel.

Rushes is a normal Mac app with a small MCP server inside it. Claude Code or Codex connects to that server the way it connects to any other tool. The agent never receives the video file. It receives text, a handful of small frames, and a list of tools for changing the edit.

The loop every edit goes through

Two of the eight steps are yours. The arrow at the end is the important one: every round of review makes the next first draft better.

05 Scenarios

Six ways people would use it

Same three players, same loop. What changes is which senses matter and where you spend your two minutes of attention.

Talking head → YouTube cut

you: brief, reviewagent: takes, pacing

The journey above. Senses that matter most: words, pauses, retakes. The headline win is removing two hours of scrubbing.

One long video → 10 shorts

you: keep / skipagent: find hooksapp: reframe 9:16

The agent searches the whole transcript for moments that stand alone. Face tracking reframes. You swipe through candidates in a minute.

Voice-over + B-roll

agent: pick shotsapp: search by meaning

“Show me typing on a laptop” finds clips in your library by meaning. The agent lays B-roll over the voice and you swap any shot with one click.

Podcast, two cameras

app: who is speakingagent: when to cut

Speaker detection gives the default camera; the agent adds reaction shots and wide shots for variety, and pulls three clips with captions.

Data or faceless video

agent: script, dataapp: render templates

For channels like Grafels charts: the agent writes data and a script, fills a chart template, and times it to the voice-over. No camera at all.

Teach it your style

you: hand editsapp: remembers

Import two edits you’re proud of. The app compares raw and final, and writes your style notes: pause length, zoom habits, caption look.

06 The agent’s toolbox

Thirteen tools, designed so the agent can’t easily do the wrong thing

The agent never writes raw JSON or runs ffmpeg. It calls a small set of tools with plain names. Each edit tool takes a reason, gets checked by the app, and answers with what actually happened.

ToolWhat the agent gets backWhy it exists
project_overview()Files, length, cameras, which senses are readyOne cheap call to orient itself
read_dossier(range, layers)The footage as text: words, pauses, takes, faces, shots, visual notesThe agent’s eyes and ears. Ask for a range and only the layers needed
search_footage(query)Moments that match by meaning, with times“me laughing”, “the screen recording of the error”
look(times, size)A contact sheet of small framesFor the few decisions text can’t settle. Kept small to save tokens
get_timeline(version)The current recipe, summarisedAlways works from the source of truth, never memory
edit(ops, reason)What changed, what got snapped, any warningsThe only way to change the video. Small typed steps, never free-form
ask_human(question, options, at)Posts a question card and returns immediatelyAsk instead of guess, without stopping work
run_checks()Failed rules with times and suggested fixesStops “I’m done” when it isn’t
get_feedback(version)Comments, answers, and your hand edits since last timeYour review becomes the next instruction
get_style()Your style notes and brand kitThe taste memory, read at every brief
make_graphic(template, data)A title, lower third or chart placed on the timelineMotion graphics from templates, not from scratch
submit_for_review(version, summary)Notifies you, opens the review screenA clear “your turn” moment
prepare_export(preset)Final checks and a render plan, waiting for your ApproveThe agent can get it ready but can’t press the button

The ops vocabulary is deliberately small: keep, cut, trim, swap_take, camera, zoom, overlay, caption_style, music, duck, transition. Cut points are given as words or times; the app snaps each to the nearest word boundary, pause and audio zero-crossing. MCP also lets the app ship resources (the dossier, the style notes) and prompt recipes such as /rough-cut, /shorts, /broll and /podcast.

07 Why it feels simple

Seven design rules

1

Review is the home screen, the timeline is optional

Most people want to watch and react, not operate. Pro controls exist, folded away.

2

Nothing waits for a render

The player follows the recipe live from proxies. You see every change the moment it happens.

3

Every change carries a reason

You can always ask “why is this cut here?” and get an answer in one line, right on the timeline.

4

Ask instead of guess, but never block

The agent picks a default, flags it, and keeps working. Your answer arrives when it arrives.

5

Rules are code, not hope

The boring correctness (frame-exact cuts, loudness, safe areas) is enforced by the app on every edit, whatever model is plugged in.

6

Undo is free, so let the agent try things

Every version is kept. A bold idea costs one click to reject.

7

You can always grab the wheel

Take over, fix a cut by hand, hand it back. Your fix becomes feedback the agent reads, not a conflict it fights.

08 More than MCP

You were right that MCP alone isn’t enough

MCP is the plug. Five other pieces make the experience feel like one product rather than a tool your terminal can call.

The app starts the agent for you

The Brief button launches your installed Claude Code or Codex in the background, with the Rushes tools attached and a ready-made instruction file. You never open a terminal. Power users can still drive it from their own Claude Code session.

An editing skill pack

The app installs a short set of recipes (rough cut, shorts, B-roll, podcast) as agent skills, so any agent starts with good editing habits instead of improvising them each time.

Notifications and a phone review link

“v1 is ready” and agent questions reach your phone. The review screen works in a browser, so you can review on the couch or send it to a collaborator.

Taste memory as a plain file

Your style notes live in a readable file the agent loads at every brief. You can read and edit it, and it moves with you if you switch agents.

A built-in brain, later

For people without a Claude or ChatGPT plan, a pay-as-you-go option using an API key. Not needed for launch, but it’s how you reach the next audience.

Template engine for graphics

Titles, lower thirds, charts and captions as web-style templates the app renders locally, so the agent fills in data instead of drawing frames.

10 Risks and open questions

What could break this plan

Subscription rules

Having the app launch a user’s Claude Code or Codex on their own plan is the cheapest path, but check Anthropic’s and OpenAI’s current terms for third-party products before you rely on it. The safe fallback is the user running their own agent session with your MCP attached, plus an API-key mode.

Agent reliability

Agents still report success when they haven’t succeeded. That’s why checks, self-review and the human Approve gate are part of the design, not extras.

Image costs

Frames are the expensive part of every call. Small contact sheets, sent only for decisions text can’t settle, keep an edit cheap.

Mac only

Native gives you speed and the media engine for free, but narrows the market. A browser review link softens this; Windows can come later.

Crowded field

Descript, CapCut, ChatCut and open-source agent kits all move fast. The defensible parts here are the timeline you own, the review loop, and the taste memory, not access to a model everyone else can also call.
