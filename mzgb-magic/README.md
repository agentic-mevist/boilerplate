# Магия и эзотерика — подготовка к квизу MozgoQuiz / «Мозгобойня»

Сайт: **https://arcana-study.pages.dev** (Cloudflare Pages). Закрыт паролем (секрет `SITE_PASSWORD` проекта, проверка — `functions/_middleware.js`) и закрыт от индексации (`noindex`, `robots.txt`).

Что внутри:

- **Квиз** — 100 тренировочных вопросов в 8 турах (по структуре тематических пакетов MozgoQuiz): разминка, три факта, картинки, таро и звёзды, алхимики и маги, ведьмы и суеверия, кино/книги/музыка, блиц. Ответ открывается по кнопке, есть пояснение «как взять», факт и источник; отметки «знал / не знал» сохраняются в браузере.
- **Шпаргалка** — квинтэссенция (70 фактов), списки для зубрёжки, актуальные новости 2024–2026, подробная энциклопедия и «вечнозелёные» факты из базы ЧГК. С поиском.
- **Как пишут вопросы** — реверс-инжиниринг метода редакции: формат, источники фактов (по 120 протрассированным вопросам), приёмы и их частота.
- **Музыка** — ~65 песен и пьес о магии со ссылками на YouTube и встроенным плеером.
- **Кино** — фильмы и сериалы о магии с «квизовыми крючками».
- **Тактика** — правила раскалывания вопросов, математика ставок, роли в команде, музыкальный тур.

## Структура

```
data/questions.json        100 вопросов (источник правды для квиза)
content/*.md               тексты вкладок (cheatsheet.md собирается скриптом)
research/                  отчёты исследования (формат, энциклопедия, дайджест ЧГК, новостные зацепки)
scripts/assemble_cheatsheet.py  head + энциклопедия + дайджест → content/cheatsheet.md
scripts/build.py           markdown → site/*.html, проверка и копирование questions.json
site/                      статический сайт (index.html, app.js, style.css, img/)
```

## Сборка и деплой

```bash
pip install markdown
python3 scripts/assemble_cheatsheet.py
python3 scripts/build.py
npx wrangler pages deploy site --project-name arcana-study --branch main   # из корня проекта, чтобы подхватилась папка functions/
```
